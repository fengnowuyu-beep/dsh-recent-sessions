# 插件的设置保存在浏览器本地存储

插件的设置弹窗有五项偏好：「显示最近」「展开工作区中的原会话」「最近区默认展示的会话数」「最近区时间过滤（天）」，以及独立的「已隐藏的会话」记录。它们保存在 `localStorage` 的 `dsh-recent-sessions/preferences.v1` 键下，组成一个 JSON 对象；缺失、损坏、字段值无效或读不到存储时，相应偏好回落到默认值。布尔值与数字分别校验：显示数量只接受数字，取整后限制在 1–50，其他值回落到 5；时间过滤只接受 0–99 的整数，默认 7，其他值回落到 7。

读取只发生在组件挂载时，点击开关后设置立即生效并写入存储；数量与天数只在按回车、离开输入框或点击右侧上下按键时生效，键入本身不会立即改变列表，确认时把越界或空白的草稿恢复为之前的有效值，上下按键每次增减 1。没有保存按钮。

标题栏齿轮与插件详情页共用同一个设置弹窗；详情页保留「打开设置」入口，因此即使隐藏最近区，用户也能重新开启它。

「已隐藏的会话」记录保存在另一个键 `dsh-recent-sessions/muted-from-recent.v1`，不并入偏好记录。原因有三点：插件是纯 Client 侧边栏装饰，Host 侧只是一个空 `apply()`；偏好放进 Host 设置需要给插件增加 Schemastery 配置、确认命名空间投影，并处理在线改写配置时的插件重载语义；这些偏好只影响本插件的列表显示和点击行为，跨浏览器同步也不是需求。同一 profile 里其他第三方插件也把浏览器本地偏好放在 `localStorage`。
