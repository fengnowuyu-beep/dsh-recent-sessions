# 最近区并入工作区列表

「最近」不再作为「工作区」区上方的独立区块，而是挂到「工作区」列表的滚动容器顶部，成为该列表的第一个分组。

宿主的 `sidebar.workspaces` 是一个 `kind: single` 的槽位，`ui-workspace` 包只声明了会话菜单、行内按钮和目录选择流程等子槽位，没有给额外的分组留注册点。因此插件只能操作 DOM：把宿主节点插进工作区列表本身，而不是插在槽位锚点旁边。

自 DSH `0.2.2-rc.2` 起，宿主给列表滚动区显式加了 `data-sidebar-list-area` 属性。插件优先用它作为落点，不再靠 `overflow-y` 计算滚动祖先：该容器的 `overflow-y` 会随内容与滚动状态变化，移除插件节点又会让样式回退，早期版本因此出现过「插入—移除」反复循环。`[role="tree"]` 仍用于确认列表已经渲染；侧栏折叠或搜索接管列表时，分组隐藏。

代价是宿主节点落在 React 管理的子树里：`ui-workspace` 在切换分组、进入搜索等时机可能重建这棵子树，插件因此保留 `MutationObserver`，在每次 DOM 变化后把节点移回列表首位。宿主改版时，这段挂载逻辑会先受影响。
